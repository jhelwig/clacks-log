# Contributing

Bug reports, feature requests, and feedback are welcome. A small reproducible
example and a description of what you expected are especially helpful. Include
the Clacks Log version and operating system when reporting a problem. Remove
credentials, personal contact logs, and private operating information before
posting.

Clacks Log is owned and published by Technosorcery, LLC and is not currently
accepting outside code or documentation patches. Please open an
[issue](https://github.com/jhelwig/clacks-log/issues) rather than preparing a pull
request. This keeps implementation and review work within the maintainer's
available time.

For security vulnerabilities, follow [the security policy](SECURITY.md) rather
than opening a public issue.

## Maintainer development

The [README](README.md#development) describes development and verification.
