# Security policy

Clacks Log is pre-alpha. Security fixes target the current `main` branch; there
are no maintained release branches or promised response times.

## Reporting a vulnerability

Please report suspected vulnerabilities privately. Do not include exploit
details, credentials, personal contact logs, or other private information in a
public issue or pull request.

When this repository is public and private vulnerability reporting is enabled,
use GitHub's [Report a vulnerability form](https://github.com/jhelwig/clacks-log/security/advisories/new).
You can also find it under the repository's **Security** tab, then **Advisories**.
While the repository remains private, coordinate directly with the maintainer
through an existing private channel. If the form is unavailable, do not fall
back to a public issue containing vulnerability details.

Include the following where possible:

- The affected revision or version and operating system.
- A description of the vulnerability and its potential impact.
- Minimal reproduction steps or a proof of concept using synthetic data.
- Any relevant configuration or diagnostic excerpts, with secrets removed.

Reports are welcome even if you cannot provide a patch. Please coordinate public
disclosure with the maintainer so a report can be investigated and a fix prepared.

For ordinary bug reports, feature requests, and feedback, see
[CONTRIBUTING.md](CONTRIBUTING.md).
